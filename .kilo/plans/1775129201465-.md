# Fix: Admin Dashboard "Failed to load statistics"

## Root Cause

The live Firestore rules **never had admin read access**. The live rules only allowed users to read their own programs:
```
allow read, write: if request.auth != null && request.auth.uid == resource.data.userId;
```
So `getDocs(collection(db, 'programs'))` was always denied for admin — the admin claim was set correctly but the rules never permitted a full collection read.

## Fix 1: User edits live Firestore rules (user action — done via Firebase Console)

Replace the live rules with:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    match /programs/{programId} {
      allow read: if request.auth != null &&
        (request.auth.uid == resource.data.userId ||
         request.auth.token.admin == true);

      allow write: if request.auth != null && request.auth.uid == resource.data.userId;
      allow create: if request.auth != null && request.auth.uid == request.resource.data.userId;
    }

    match /sharedCode/{shareId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if false;
    }
  }
}
```

## Fix 2: Sync repo firestore.rules to match live rules exactly (code change)

The repo's `firestore.rules` is already correct — no change needed there.

## Fix 3: Code change — resilient data loading in AdminDashboard

Currently `loadData()` uses `Promise.all([getStats(), getAllPrograms()])` — if either fails, everything fails and nothing shows.

Change to `Promise.allSettled` so stats and programs load independently. If one fails, show a targeted error for that section while the other still displays.

### `src/components/AdminDashboard/AdminDashboard.tsx`
- Replace `Promise.all` with `Promise.allSettled`
- Add separate `statsError: string` and `programsError: string` state (remove single shared `error` state)
- If stats result rejected → set `statsError`, leave stats null, show error in stats section
- If programs result rejected → set `programsError`, show error in programs section
- Remove redundant `setLoading(false)` calls inside `loadData()` — already handled in `checkAdminStatus` finally block

## What NOT to change

- `firestore.rules` in repo — already correct
- `adminService.ts` — queries are correct
- Auth / ProtectedAdminRoute — working correctly
